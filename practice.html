LOCAL PROJECT · PYTHON STANDARD LIBRARY

Build a retrieval
baseline.

Practice searching fictional documents, inspecting evidence and writing tests. This project runs on your computer, not inside the website.

Scope: word-count cosine similarity over three fictional passages. This is not a trained embedding model, vector database, chatbot or complete RAG system.

Run the project

  1. Install Python 3 if needed. No extra Python packages or accounts are required.
  2. Download retrieval_lab.py and test_retrieval_lab.py into the same folder.
  3. Open a terminal in that folder and run the commands below. On some systems use python3 instead of python.
TERMINAL · RUN LOCALLY
python retrieval_lab.py "How do I reset my password?"
python retrieval_lab.py "Where is the cafeteria?"
python -m unittest -v test_retrieval_lab

The first question should find the Account guide. The second should report no matching evidence. Never invent an answer from a missing source.

Your engineering assignment

  1. Add a fictional passage with a unique source ID. Use only data you have permission to process.
  2. Add a supported and an unsupported test question. Run the tests and explain any failure.
  3. Find an irrelevant passage with overlapping words. Explain why similarity does not prove a claim.
  4. Sketch where access control, embeddings, a vector index, generation, citations, evaluation and monitoring would fit. These components are not implemented here.
