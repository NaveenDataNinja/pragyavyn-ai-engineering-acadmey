BROWSER PRACTICE · NO ACCOUNT

Find evidence.
Then decide.

Act as a retrieval engineer. Ask a question, inspect the ranked fictional passages, and decide whether the evidence is enough to answer.

What this is: a local, word-count cosine similarity demonstration. It is not a trained embedding model, vector database, chatbot or live RAG system. No question is sent to a server.

Your retrieval workbench

Try “How do I reset my password?” and then “Where is the cafeteria?” The second question has no supporting passage.

Think like an engineer

  1. Identify the query words that overlap with each passage. The score compares word-count vectors, not meanings.
  2. Read the source before answering. A matching word alone does not establish that the answer is supported.
  3. If no passage answers the question, abstain. A real system also needs access controls, evaluation and citation checks.

Try the local Python project instructions. It uses synthetic data and runs without model downloads. For an optional real-model project, build the workplace assistant.

Does a high similarity score guarantee a correct answer?

No. It ranks candidates based on this simple calculation. Inspect the passage and evaluate the full system.
